# Visual acceptance checklist

Inspect actual output beside its references. Correct prompt wording does not prove correct output.

| Check | Acceptance criterion |
| --- | --- |
| Canvas | One landscape image; actual width:height 16:9 where dimensions are accessible |
| Views | Exactly two: front left, true rear right |
| Identity | Same garment set, cut, dimensions, palette, materials and layering |
| Evidence | Observed details preserved; unseen structure not claimed as verified |
| Orientation | Actual rear rotation, not mirroring; garment-relative asymmetry preserved |
| Front-only details | No unsupported front logo, placket or pocket duplicated on the rear |
| Removal | No body, skin, hair, mannequin, support or transparent human shell |
| Framing | Full sleeves, hems, legs and relevant accessories inside the canvas |
| Construction | No extra components, broken straps, fused layers or impossible seams |
| Material | Plausible thickness, folds, reflections, weave and transparency |
| Presentation | Equal scale/alignment, warm ivory, matched lighting |
| Text | No added captions/watermarks; original readable marks preserved |

Prioritize wrong view, wrong clothes, body remnants and structural contradictions over minor photographic imperfections. Repair locally where possible and recheck shared structure. After two unsuccessful repairs, disclose the remaining issue.

Mark inaccessible checks as unverified. Never claim the skill is benchmarked or production-validated solely because this checklist exists.
